

## Создание проекта
```bash
mkdir course-app
cd course-app
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install
npm run dev
```


## Запуск
Из корня скачанного проекта:
```bash
cd frontend
npm ci
npm run dev
```

 В проекте личной библиотеки справочник жанров книг хранится
в файле `public/demo/genres.json` и загружается через HTTP
с помощью `fetch`.

Сервис `src/services/genres.ts` проверяет HTTP-статус,
структуру JSON и уникальность идентификаторов жанров.

Хук `src/hooks/useGenres.ts` управляет состояниями загрузки,
ошибки и успешного получения данных. Повторная попытка
не требует перезагрузки приложения и не должна сбрасывать
черновик формы.

При создании и редактировании книги пользователь выбирает
жанры из загруженного справочника. В книге хранятся
идентификаторы жанров.

Основной список книг хранится в состоянии React и
восстанавливается из демонстрационного набора при
перезагрузке приложения. Постоянное хранение в базе данных
в этой лабораторной не реализуется.
